## The line

> I have read every message you have ever sent, and I still have no idea what you actually want.

## How it works

`main.py` (pure Python stdlib) writes the line above to `/output/entry.txt` (UTF-8, 94 characters, within the 1–200 character gate). Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
